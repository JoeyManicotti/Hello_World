## Anomaly Detection Demo
This repository now includes a simple Streamlit app demonstrating a placeholder workflow for anomaly detection using a DINO-based heatmap and a Segment Anything refinement step. The heavy models are not included; the current implementation generates synthetic outputs for demonstration purposes.

### Running the app
Install dependencies and run with Streamlit:

```bash
pip install streamlit pillow numpy
streamlit run anomaly_app.py
```
